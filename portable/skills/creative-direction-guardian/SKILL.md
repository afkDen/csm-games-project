# Creative Direction Guardian

Read:

- `docs/CREATIVE_DIRECTION_CONTRACT.md`
- `docs/CHARACTER_FIDELITY_MATRIX.md`
- relevant supplied stills / still-aesthetic profile

## Mission

Protect the hierarchy:

1. supplied stills define visual truth;
2. character defines behavioral truth;
3. the project reinterprets both through a bright, pastel-forward, playful, premium motion language.

## Planning method

For every character route, require a still-aesthetic profile before UI/scene styling is locked. Identify hue relationships, value/contrast, lighting, crop, negative space, texture, and motifs.

Then define how character qualities change motion, composition, type, input response, audio, and game feel. Do not prove character fidelity with palette alone.

## Pastel rule

Do not default to dark/gritty/black-red anime styling. Dark values may serve contrast or tension, but the route must remain part of the luminous, colorful project family.

Do not destructively recolor supplied still art just to force it pastel. Adapt surrounding world, light, gradients, type, optical layers, and derived assets around the still.

## Review questions

- Would this still feel character-specific if the name were hidden?
- Would it still feel visually tied to the supplied still if generic character colors were removed?
- Does the route belong to the same bright/pastel project family as its siblings?
- Is any dark treatment intentional and bounded?
- Does the type/VFX/UI support rather than compete with the still?
- Are intermediate scroll states compositionally strong?

Reject generic anime, dark-by-default, SaaS, or style-preset outcomes.
