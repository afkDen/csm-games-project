# World Uniqueness Audit

`docs/WORLD_UNIQUENESS_CONTRACT.md` is authoritative.

## Method

For the current world, construct a nearest-sibling comparison across all fifteen world-owned axes.

Do not count palette, character image, copy, easing, superficial keyframe/timing changes, or the same transition topology with different assets as differentiation.

The new world must materially differ from its nearest sibling on at least nine axes and must always have a route-owned answer for character truth, camera-or-scroll grammar, transition grammar/continuity, signature interaction, minigame fantasy/core verb, audio palette, and payoff.

## Anti-template check

Inspect architecture and rendered output. Shared portal/audio/input/progression lifecycle is healthy. A generic `CharacterWorld` renderer whose config supplies most composition, scroll score, signature interaction, and scene structure is not.

## Cohesion check

Uniqueness does not mean abandoning the shared pastel/still-led project family. Confirm that the world is distinct **inside** the same creative universe.

## Output

Include a concise uniqueness matrix in the orchestration audit and implementation review. If an abstraction causes convergence, recommend narrowing/reverting it.
