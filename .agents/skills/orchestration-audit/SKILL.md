# Orchestration Audit

Read `docs/AGENT_LOOP_PROTOCOL.md`, `docs/CAPABILITY_ROUTING_POLICY.md`, the proposed milestone packet, and the locked creative contracts.

## Independence rule

Do not rubber-stamp the orchestrator. Reconstruct enough of the problem from repository contracts, supplied assets, existing implementation, and applicable skills to form an independent judgment.

## Skill-active audit

For a character route, normally inspect/use as materially applicable:

- `creative-direction-guardian` — still-led pastel hierarchy + character fidelity;
- `scroll-experience-director` — 0–100 score, continuous input, peak, reverse/dead-scroll logic;
- `transition-continuity` — canonical state, property ownership, reverse/retarget/cancel behavior, mid-transition controls, portal/game handoff;
- `spatial-depth-director` — meaningful depth and flatness risk;
- `still-to-cinematic` — source-art decomposition/integrity;
- `asset-scout` — asset-gap map and sourcing/generation/procedural decisions;
- `media-pipeline-ffmpeg` — when the selected beat needs media inspection/transcoding/frame extraction/audio preparation;
- `world-uniqueness-audit` — nearest-sibling differentiation;
- `minigame-systems` and `game-audio-systems` — playable/audio depth;
- current technical documentation when version-sensitive APIs matter.

A technically valid plan can still fail for being dark-by-default, generic, flat, section-based, weakly character-authored, repetitive, shallow, under-researched, over-optimized, or insufficiently verifiable.

## Audit questions

1. Does the still-aesthetic profile actually drive palette/composition/light/texture?
2. Is character truth translated into behavior rather than only image/color?
3. Is the route clearly in the pastel/colorful project family without erasing still fidelity?
4. Is there a contiguous 0–100 experience score with meaningful scroll consequences?
5. Does the route own a materially distinct transition grammar, with canonical state/property ownership and reverse/retarget/interruption behavior?
6. Is there one character-owned signature interaction and one engineered peak?
7. Are flatness risks addressed with meaningful depth relationships/camera crossing?
8. Is asset discovery tied to identified gaps rather than arbitrary stock collection?
9. If selected media needs derivative preparation, is FFmpeg/FFprobe or an equivalent explicitly routed and reproducible?
10. Does performance strategy protect primary choreography and degrade secondary cost first?
11. Are desktop/mobile/reverse/retarget/idle/audio/game/lifecycle states testable, including 25/50/75% direction flips and eligible mid-transition controls?
12. Does the route pass the uniqueness contract against completed siblings?
13. Are risky technical assumptions scheduled as focused proofs before broad implementation?
14. Did the capability routing consider the actual current tool/skill set without checklist theater?

## Output

Write `ORCHESTRATION_AUDIT.md` with `APPROVED FOR IMPLEMENTATION` or `REVISE` and concrete blockers/corrections. Do not edit production code or silently rewrite the packet.
