## Game design

Working title “One More Run”; original character-inspired game, not a canon event. The supplied human-form chibi rides a visibly original optical carriage through a shallow three-lane graphic track. A frontal/three-quarter camera preserves the supplied face/gesture while the track streams toward the player; no invented running cycle, weapon swing or transformation animation.

**Dominant verb:** hold to charge, release to dash, coast to cool. Supporting systems: heat limits continuous effort; unbanked token chains create risk; telegraphed gates require lane choice. Standard run lasts exactly 60 simulation seconds (3600 ticks at 60Hz), excluding pause/ready. The world stream advances on simulation time; dash changes the avatar's bounded forward offset/interaction envelope, not the global clock or bank-window schedule. Lane changes take .18s; collision uses the continuous position, never teleporting across lanes.

Values are explicit initial rules; implementation may tune numbers from play evidence while preserving the defined decisions and recording changes.

- Initial: resilience H=3; charge Q=0; heat T=0; unbanked chain C=0; secured tokens S=0; successful bank count B=0; tick=0; no held inputs/dash/cooldown; fresh seed/run ID.
- Q and T clamp to [0,1]. While charge held and not overheated/dashing, Q rises .8/s and T rises .30/s. Releasing with Q≥.2 starts dash duration .4+.6Q seconds and consumes Q to zero; release below .2 simply clears Q. Holding at full charge still raises heat.
- Dash has a concrete traversal benefit: a clearly serrated, marked breakable gate opens on contact only during an active dash. Opening consumes that dash, records the gate ID as opened and adds one token to C once. Solid charcoal gates never break and must be avoided by lane choice. A closed breakable gate hit while coasting causes the ordinary collision penalty. The renderer distinguishes these shapes before contact; no color-only rule. Gate opening resolves in the hazard step before damage, and collision in that tick still clears any earned chain. Optional higher-value branches put pickups beyond breakable gates; dash is a route-planning verb, not only a visual speed effect.
- T≥1 cancels charge/dash, clears Q and enters overheat coast. T cools .25/s whenever not charging; overheat exits at T≤.4. A fresh press edge is required to charge again, preventing held-key restart. Dash cannot retrigger while active; ordinary coast has no charge input held.
- Each unique orange pickup adds exactly one token to C once. Token IDs prevent duplicates. Tokens do not auto-bank, heal or modify heat. Missing a token changes no state. Unbanked tokens have no secured-score value at finish.
- Collision with a closed gate/obstacle removes one resilience, clears C/Q/dash, sets T=max(T,.5), and grants 1.0s collision immunity. S and B remain. A fresh charge press is required. If H reaches zero, failure ends the run immediately; immunity cannot prevent the collision that caused failure.
- Bank zones are timed safe stretches [12,15), [27,30), [42,45), [57,60) seconds. Each has its own unique ID and accepts **at most one successful bank**. No damaging obstacle or moving gate enters the player envelope in these intervals; all three lanes access the same bank zone.
- Bank eligibility: playing, inside an active unspent zone, C≥3, T≤.4, no active dash, no collision/immunity recovery, and an explicit Bank press edge. On success atomically S←S+C, C←0, B←B+1 and mark zone spent. Display “Banked N” and secured total. There is no passive bank or repeated held-button banking.
- Ineligible Bank changes no gameplay values. The control exposes the reason: “Collect 3”, “Cool down”, “Coast first”, “Recovering”, “Next bank”, or “Already banked”. Priority is outside/spent zone, insufficient tokens, recovery, dash, heat. Mute does not remove this feedback.
- Tick order: collect input edges → update motion/heat/overheat and zone → resolve hazards and at-most-one collision → collect surviving pickups → evaluate Bank edge if still playing and not recovering → evaluate terminal state. Collision and Bank in the same tick cannot preserve the chain. At tick 3600 the bank windows are closed; presses on the exact finish boundary do not count.
- Success at tick 3600 requires H>0, S≥9 and B≥3. Otherwise failure reason is exhaustion or insufficient secured deliveries. Score is 10×S; best-result tie breakers are fewer collisions then lower cumulative overheated time. Unbanked C is discarded at result entry. No further pickups/banking/simulation occurs after terminal state.
- Replay creates a fresh run ID and fully resets H/Q/T/C/S/B, tick, zone flags, pickup IDs, hazard state, held inputs, camera offsets and audio voices. Normal replay may use a new seed; debug replay can reuse seed and input log. Persistent completion/best result remain independent and commit once per validated successful run ID.

### Fairness and escalation

Guaranteed baseline schedule offers at least four safely reachable tokens (including opened-gate rewards) on a traversable path before each bank window, using ordinary charge/dash/lane decisions with no requirement to hit maximum dash speed. At least one clearly telegraphed breakable gate introduces the dash verb in the first phase. A compliant low-risk player can reach at least three banks; taking tempting alternate chains raises score but increases collision/heat pressure. Seeded variation may change lane choice but must preserve the guarantee and telegraph budget. Before a safe bank stretch, leave sufficient coast time to cool from T=1 to ≤.4 (at least 2.4 seconds under the rules) and recover from an ordinary hit; never place a mandatory charge immediately before banking.

0–20s: fixed separated gates and tokens teach charge/coast and the first bank. 20–40s: a telegraphed gate lane changes once before locking, requiring a lane decision before dash commitment. 40–60s: alternate high-value token branch beyond staggered gates competes with the safe low-risk path and third/fourth bank. Ensure ≥1.0s visible telegraph at worst allowed dash closing speed; validate actual timing. This changes decisions, not only spawn rate. 90s mastery mode is deferred, not standard scope.

Keyboard: A/D/arrows lane, Space charge/release, E bank, Escape pause. Touch: ≥44×44px charge, lane controls, separate Bank; pointercancel clears charge without triggering an unintended dash. Pause/blur/ownership loss clear held input without interpreting release as dash. Resume requires explicit unpause and fresh input. Native route scroll cannot fight game controls.

Pause freezes simulation, including an already active dash's remaining duration and forward offset, and clears unlaunched Q and input edges; it does not cool heat, move hazards, collect tokens or bank while hidden. Resume retains frozen T/C/S/B/H/time/zone flags and continues any previously active dash from that exact state, with no catch-up and a fresh press needed for new charge. This prevents pause cancellation from dropping the player into a closed gate. Route exit ends the run without banking C; it preserves only previously committed persistent best/completion. Ready and Replay never inherit an earlier run's held key or pointer capture.

State: idle → ready → playing ↔ paused → success|failure → results → replay|exit. Fixed-step seeded rules are separate from render objects. Clamped accumulated time prevents hidden-tab catch-up. Debug seed/tick/phase/zone/eligibility/collision bounds behind a development flag enable replay and fair-pattern checks.
