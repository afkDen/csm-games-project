## Shared lifecycle, world-owned choreography

The route shape is connective tissue only. Each branch must own its still interpretation, character behavior, pastel tonal translation, composition, spatial-depth strategy, 0–100 scroll score, transition grammar, signature interaction, engineered peak, portal staging, audio, game fantasy, payoff, and mobile translation. Shared lifecycle states must not become one repeated crossfade/zoom/mask sequence.

Do not infer that this diagram authorizes one reusable route layout.

## Hub progression

The hub should visibly remember completed worlds while remaining an expressive visual stage rather than a checklist UI.

Potential completion feedback:

- lens material/refraction changes;
- color/gradient relationships evolving with completed worlds;
- subtle frame illumination;
- new reflection or embedded scene;
- small collectible/result marker integrated diegetically;
- additional spatial layers / lens relationships;
- final portal/world unlock after all routes.

The hub itself should respond to scroll/pointer/touch where useful and feel alive between selections. Progression should remain mostly diegetic.
