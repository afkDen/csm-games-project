# Emil Policy — Bounded Review Only

`emil-design-eng` is optional and intentionally **not** the continuous creative authority for this project.

## Allowed invocation points

Prefer using it at only two moments:

1. after the first complete vertical slice;
2. during final whole-site motion polish.

## Appropriate concerns

- interruption behavior
- damping / spring feel
- hover/press response
- input ownership
- transition continuity
- timing mistakes
- motion that reads as accidental rather than authored

## Not authorized

- normalizing all character worlds into one motion language
- deleting theatrical camera motion merely because a calmer UI pattern exists
- replacing route-specific choreography with generic micro-interaction conventions
- global motion reduction as a default solution

## Usage log rule

If used, the log must explain the actual before/after motion issue and include the marker:

`ambition=preserved`

A generic “reviewed animations” entry is insufficient.
