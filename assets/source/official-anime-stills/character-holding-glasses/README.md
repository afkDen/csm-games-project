# Owner-Supplied Character / Glasses Stills

Place the original campaign/anime still images that you intend to work from here.

This folder is ignored by Git by default. Do not scrape these assets automatically and do not move originals into `public/` during exploration.

When an image is selected for production:

1. record provenance/rights notes;
2. create only the needed optimized/cutout/depth derivatives;
3. place shipping derivatives under `public/assets/derived/`;
4. add/update the `ASSET_MANIFEST.json` entry.
