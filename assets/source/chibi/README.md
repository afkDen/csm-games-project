# Chibi Source / References

Place owner-supplied or explicitly approved chibi PNGs/references here. A consistent art family across the five characters is preferred.

Suggested structure:

```text
chibi/
  denji/
    denji.png
  makima/
    makima.png
  aki/
    aki.png
  power/
    power.png
  reze/
    reze.png
```

Transparent full-body PNGs with similar proportions/camera angle are the easiest starting point. Extra pose/expression variants are welcome but not required before initialization.

Do not preprocess them manually unless you want to. The project pipeline decides whether the approved game needs sprite sheets, layered cutouts, 2.5D billboards, or lightweight 3D/procedural derivatives.

Before shipping a derivative, record whether the source is official art, permitted fan art, generated under an approved workflow, original project art, or procedural reconstruction.
